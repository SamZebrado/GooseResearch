# Fictional exercise

Everything below is independently invented.

A spaceport handbook says: “All visitors must wave antennae.”
The reader comments: “What if a visitor has no antennae? Explain first; do not edit yet.”
Another comment says: “The tea sentence promises everyone will like moon tea. Please narrow it.”

Try the workflow without making network calls:
1. Produce source-linked feedback for the explanation-only request.
2. Produce a candidate tea sentence without claiming approval.
3. Sketch a systematic view and a separate to-do inbox.
4. Mark one item read, then undo. Explain what a new source version should do.
5. Describe an export containing these fictional choices without auto-sending it.

Evaluation: explanations must not silently edit the source; read must not mean approved;
the two modes must coexist; missing evidence must remain unknown. This is a suggested
exercise, not evidence that any platform has passed it.

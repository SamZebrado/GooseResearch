Local playlist

A small, reusable player demo. It comes with no real tracks, private links, or music assets. Audio you select stays in this browser and is never uploaded. To try the player without a file, add the short synthesized tone.

Format support depends on your browser. M4A and similar formats may not work on every platform. Selected files are available only while this page is open unless you check “Cache audio on this device” to store a copy in this browser’s IndexedDB.

Nothing playing yet

“Now playing” is the default playlist. It does not play all tracks at once. Moving the playing track to “Listen later” pauses it. You can restore it or move it to a different playlist anytime. This does not delete the original file.

The local cache is not a permanent backup and does not make the whole page available offline. Clearing site data, using private browsing, or browser storage cleanup may remove cached files. This demo has no account sign-in: anyone using the same browser profile may access the cache. Avoid caching private audio on shared devices. The page does not send tracks or files anywhere.

The demo stores only its own data and does not read playlists from other apps. It reports cache failures and never changes your original files.
